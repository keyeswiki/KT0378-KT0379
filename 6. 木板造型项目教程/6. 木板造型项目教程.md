#### 6.1.1 硬件连接

| 模块 | 引脚 | 说明 |
|---|---|---|
| RGB 模块 | IO10 | 4 颗灯珠 |
| 有源蜂鸣器 | IO3 | 播放提示音和音乐 |
| 步进电机 IN1 | IO8 | 28BYJ-48 驱动 |
| 步进电机 IN2 | IO9 | 28BYJ-48 驱动 |
| 步进电机 IN3 | IO13(rover主板接排针48) | 28BYJ-48 驱动 |
| 步进电机 IN4 | IO14 | 28BYJ-48 驱动 |

#### 6.1.2 核心逻辑

这个造型注册了两个 MCP 工具，语音指令通过 AI 大脑触发：

1. **musicbox**（布尔值 state）：
   - 开启：步进电机开始旋转、RGB 切换为彩虹循环效果、蜂鸣器播放生日歌；
   - 关闭：电机停转、蜂鸣器停止、RGB 熄灭。
2. **RGB**（brightness 亮度 + effect 灯效）：
   - 可以独立控制 RGB 亮度和灯效（常亮 / 闪烁 / 呼吸 / 彩虹 / 流水 / 彩虹循环等）。

步进电机使用 `micros()` 计时，每 5000 微秒走一步，走完 2048 步（半圈）后自动反转，实现往复旋转，而不是用 `delay` 阻塞。

#### 6.2.1 硬件连接

| 传感器 | 引脚 | 类型 |
|---|---|---|
| 热敏电阻（温度） | IO2(cam主板接IO15) | 模拟量输入 |
| 光敏电阻（光线） | IO3(cam主板接IO16) | 模拟量输入 |
| 气体传感器（空气） | IO9 | 模拟量输入 |

#### 6.2.2 核心逻辑

三个传感器分别注册为独立的 MCP 工具，AI 在被问到对应问题时主动读取数值：

| 工具名 | 作用 | 返回值 |
|---|---|---|
| temp | 读取温度 | 摄氏温度值 |
| light | 读取光线 | 光敏电阻原始值 |
| gas | 读取空气质量 | 气体传感器原始值 |

温度换算：模拟读数 × 3300 ÷ 40950，得到摄氏温度值。

#### 6.3.2 核心逻辑

注册两个 MCP 工具：

1. **motor**（布尔 state）：手动浇水——true 开泵（速度 120），false 关泵。
2. **soil**（布尔 state）：自动浇水模式——开启后循环检测土壤湿度，太干时自动开泵浇水约 4 秒；关闭时立即停泵。

湿度换算：`(读数 - 450) × 100 ÷ 2900`，数值超过 80 判定为土壤偏干，触发浇水。

### 6.5 关键知识点总结

1. **MCP 工具就是"语音入口"**：每个外设通过注册一个 MCP 工具，AI 才能在对话中调用它。工具名、参数名要和代码一致。
2. **模拟传感器 vs 执行器**：热敏、光敏、气体、土壤湿度是"读"（analog read），电机、舵机、RGB、蜂鸣器是"写"（输出）。
3. **非阻塞控制**：步进电机、水泵延时都用 `millis()` / `micros()` 计时，不要用 `delay()`，否则语音和 Wi-Fi 会卡住。
4. **布尔参数的好处**：用 true/false 表示开/关，语音说"打开音乐盒"AI 就能映射成 true，逻辑简单清晰。
